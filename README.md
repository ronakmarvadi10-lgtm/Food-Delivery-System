# Food Delivery System

A beginner-friendly frontend-only React + Vite food delivery demo.

## Run the project
1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. Open Terminal and run `npm install`.
4. Run `npm run dev` and open the local URL shown in the terminal.

## Features
- Responsive food menu with 15 items, search, and category filters
- Cart with quantity controls, remove item, and total
- Demo checkout and order history saved in browser localStorage
- Register/login, profile details, and demo password change

**Important:** This is a frontend learning project. It has no backend, real payment, email reset, or secure password storage. Do not use real passwords.
